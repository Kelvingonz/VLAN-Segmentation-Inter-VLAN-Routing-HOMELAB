# VLAN-Segmentation-Inter-VLAN-Routing-HOMELAB

<img width="745" height="352" alt="INTERVLAN" src="https://github.com/user-attachments/assets/30925e57-78bd-4f93-8742-099e27e122e2" />


In this project, I used Cisco Packet Tracer to configure Inter-VLAN routing using a multilayer Layer 3 switch, enabling communication between multiple VLANs within the LAN. I established a point-to-point Layer 3 connection between the router and multilayer switch and configured the appropriate IP addressing for communication between devices. I also created and configured Switch Virtual Interfaces (SVIs) for VLANs 10, 20, and 30, assigning IP addresses to serve as the default gateways for each subnet. Finally, I tested connectivity between the VLANs and verified Internet connectivity by pinging 1.1.1.1, confirming that communication across the network was functioning correctly.
